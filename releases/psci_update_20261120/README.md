## 网络优化

02后半部分新增 `OptimizedResNet`：图像特征2048→256维，病灶分支256→64维并采用GroupNorm，四层使用门控注意力。前3轮只训练新模块，之后只微调ResNet的layer4，骨干BatchNorm保持固定；骨干学习率1e-5，新模块5e-4。

优化版在每个外折的训练患者中留出20%选择轮数，然后重新初始化、训练该外折的全部训练患者，最后评估外折。原增强、加权BCE、AdamW、梯度裁剪、批大小16、最多30轮和耐心值8继续沿用。结果在 `optimized/resnet_v1/`，不会覆盖 `temporal/` 中已有基线。

原临床融合保留；本次没有新增优化版临床融合。开发OOF同时受模型结构和轮数选择流程影响，不能将指标变化全部解释为某个结构的贡献。是否提高AUC要由实际训练和验证判断。

## 两台电脑如何衔接

1. 两台电脑更新7本Notebook和 `experiment_settings.json`，保留各自的 `config.json` 与 `outputs/`。更新后重启Notebook内核，重新执行定义单元。
2. 算力机在02最后开启 `RUN_OPTIMIZED_TRAINING`。已有原模型无需重跑。
3. 数据电脑在01提取特征。可导出仅特征包供异地训练，也可在本机训练两组对照并导出完整包。完整包带有固定模型的时间验证预测，算力机06直接读取，不要求安装PyRadiomics。
4. 数据电脑在05导出四层数据集、预处理、安装患者分折、训练五折、预测和评价，再生成分类用自动掩模。
5. 从01或05导出的文件夹位于 `transfer_packages/`。上传完整文件夹到算力机 `incoming/`，用对应Notebook的导入单元接收。接收目录已有结果时不会覆盖；换实验名保留旧结果。
6. 在06按准备情况开启 `INCLUDE_OPTIMIZED`、`INCLUDE_RADIOMICS`、`INCLUDE_AUTOMATIC_MASK_SUBSTITUTION`，再运行报告。新报告默认写入 `reports/comparison_v2/`。

| 包类型 | 内容 | 算力机用途 |
|---|---|---|
| 影像组学特征包 | 患者特征表、提取参数和记录 | 训练对照；需要与现有环境兼容的scikit-learn |
| 影像组学完整包 | 特征、模型、开发OOF、固定阈值、时间验证预测 | 直接进入06比较，无需加载异地joblib模型 |
| 分割结果包 | 四层自动掩模、开发/时间验证分割指标、来源与划分记录 | 分类输入替换及统一报告 |
| 分割权重包 | 五折最终权重、plans、dataset、版本记录 | 在兼容nnU-Net环境恢复原分辨率推理 |

完整权重不能代替推理输入。算力机只有224×224分类缓存时，应上传分割结果包；若要在算力机做新的分割预测，还需提供按05导出的原分辨率单层三序列影像。权重推理命令使用导出时的nnU-Net版本。

## 这版实验的边界

- 四层之外没有标注，不作为训练背景或评价真值。分割仍依赖人工取层，不能称为完整全脑自动流程。
- 影像组学逐层提取，按患者汇总；形状单位是像素或像素平方。分割HD95是平面像素距离。原空间单位及层间距未核实前不报告毫米或完整病灶体积。
- 标签1/2/3先保留数字名称，不猜测医学含义。
- 原模型和03仍采用原外折早停；原一次OOF临床融合也没有变为全流程嵌套。优化版的内层选轮数不能“修正”既有基线结果。
- 自动掩模对照只替换原分类器输入，没有用自动掩模重训分类器，也没有实现整条流程的嵌套交叉拟合。
- 所有阈值在开发阶段确定。时间验证不参与调参，反复查看后选择方案会影响独立性。
