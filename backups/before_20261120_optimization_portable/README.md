## 先检查一例，再处理全量

同级 `moca.xlsx` 已有206例临床记录，目前这里只放了一例影像。已按实际表头配置“影像号”、MoCA、取层、同型半胱氨酸和尿酸等字段。

检查这一例时，在00的配置单元选择 `CONFIG_FILE = "config.sample.json"`。该配置读取当前目录的 `MR251203027`，输出到独立的 `sample_check_20261118` 实验目录；只生成样例缓存，不生成时间分组或训练包。

全量处理时，选择 [config.json](config.json)，填写 `patients_root`，指向直接包含各患者文件夹的目录。患者文件夹可以叫 `姓名 MR编号` 或 `MR编号`，每例的“配准图像”里需要：

```text
t1_flair.nii.gz
t2.nii.gz
dwi_b1000.nii.gz
Untitled.nii.gz
```

按00中编号执行：整理临床表 → 匹配患者 → 检查影像 → 生成四层缓存 → 保存时间分组 → 导出上传包。运行开关默认关闭，每步确认结果后再继续。在已有依赖的环境执行；本机不提供自动安装或启动服务的单元。

已有缓存可填写 `existing_cache`，在00中开启 `RUN_VERIFY_EXISTING_CACHE`。它会核对编号、结局、取层，并按当前影像重新计算后逐例比较；不能只凭文件名认定缓存可用。

每个独立实验使用不同 `run_id`，主要产物不覆盖。全量模式仍要求206例及2026-06-10分界日期，缺文件或检查失败时会停止，不会缩小队列后继续训练。

`clinical_adapter.xlsx`是派生副本，源Excel不改写。它统一旧代码的两个MR位置和临床固定下标，同时排除缺失结局并留记录；临床数值和原结局阈值不改变。影像纳入仍需原取层、文件及新输入完整性检查，因此真实数据核查后患者数不一定自动满足历史记录；不满足时应先核对而非修改断言凑数。

00会保存以下记录：

| 文件 | 查看什么 |
| --- | --- |
| `clinical_issues.csv`、`excluded_missing_outcome.csv` | 编号、日期和 MoCA 问题，对应源表行号 |
| `patient_matching.csv`、`duplicate_directories.csv` | 临床患者与目录是否一一对应、四个文件是否齐全 |

样例的标注范围记录为 `selected_slices`；其他患者默认 `unconfirmed`，逐例信息可填写在 `preprocessing.annotation_scope_by_mr`。不能因本例只标四层就推定所有患者相同，也不能把未标注层当作无病灶。

空间单位不明、DICOM 与 NIfTI 层间距不同会保留提示，不自动修改影像。分类仍按原数组方式处理。三维影像组学与分割入口会检查数据是否可用、是否完整标注；三维物理特征还要求空间核查通过。01、05的局部标注流程留待后续开发，标签1/2/3的医学名称也仍需确认。

## 原方法保留了什么

- 原四层选择、三个图像与三个病灶通道、224×224、1%–99.5%归一化及原数据增强。
- 原ResNet50＋病灶CNN＋切片注意力，原单序列模型和ImageNet首层初始化。
- 原随机种子、batch=16、AdamW、两个学习率、损失、最多30轮及patience=8。
- 原开发五折后按最佳epoch中位数重训的最终单模型。
- 原五临床变量、中位数填补、标准化、C值列表及逻辑回归晚期融合。

没有加入ROI引导的新网络、特征压缩、位置编码、冻结策略、Transformer、概率校准或影像模型集成。

原时间评估文件中的“开发临床拟合”移到02，保存原方法的对象；06只加载预测，不重新fit。所有方法仍由相应开发OOF选择Youden阈值。增加的校准图和Brier是评估，不是在验证集拟合校准器。

## 需要如实保留的局限

1. 原影像验证折同时用于选epoch和报告AUC；原一次OOF晚期融合也不是整套嵌套隔离。本版没有将它们描述为已修正。
2. 新影像组学采用全三维ROI，而原DL只有四层，输入覆盖不同。特征筛选在内层完成，但不能把两组差别全归因于算法。
3. 现有61例验证结果已被查看，不应反复根据该组选择方案。Bootstrap区间仅针对固定预测的病例抽样不确定性。
4. 03包含三组单序列与去病灶、去注意力两组结构消融，目前都用于开发五折比较，没有为消融组另加时间验证训练流程。04尚未完成随机化、遮挡和系统稳定性实验。
5. 05提供分割数据、训练及推理入口，不能在没有真实数据验收时声称已训练出分割模型。
6. 分割开发OOF不能直接等同于分类整条流程的嵌套OOF。06的自动输入选项只做“原人工掩模分类器替换自动掩模”的敏感性实验，没有用自动掩模重训分类器，且仍使用人工最大层。完整自动联合开发另行开展。
